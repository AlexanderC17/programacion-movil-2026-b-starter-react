# Lista de verificación del parcial

- [ ] Integrar el contenido en el starter oficial de Ionic React del curso.
- [ ] Confirmar `node --version` (22.12 o superior).
- [ ] Ejecutar `npm install`.
- [ ] Copiar `.env.example` a `.env` y revisar `VITE_API_URL`.
- [ ] Ejecutar `npm test`, `npm run build` y `npm run lint`.
- [ ] Probar manualmente los cinco endpoints y las cuatro pantallas.
- [ ] Abrir Kotlin Playground y ejecutar `kotlin/Product.kt`.
- [ ] Crear fork y rama `feature/catalogo-productos`.
- [ ] Hacer primero un commit exclusivo de documentación.
- [ ] Realizar al menos seis commits Conventional Commits propios.
- [ ] Abrir PR hacia `main` del propio fork con descripción y checklist.
- [ ] Pegar el enlace del PR en Moodle antes del cierre.

No incluir `node_modules/`, `.env` ni secretos.
