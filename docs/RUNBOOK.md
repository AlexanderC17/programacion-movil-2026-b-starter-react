# Guía de ejecución

## Requisitos
- Node.js y npm instalados.
- Git instalado.

## Instalación
Desde la raíz del proyecto, ejecutar:

```bash
npm install
```

## Ejecución del frontend
```bash
npm run dev
```

## Ejecución del servidor
```bash
npm run server
```

## Verificación del proyecto

### Pruebas automatizadas
```bash
npm test
```

### Compilación
```bash
npm run build
```

### Revisión estática
```bash
npm run lint
```

Observación: el script actual de `lint` imprime un mensaje informativo y no ejecuta un analizador estático real.
