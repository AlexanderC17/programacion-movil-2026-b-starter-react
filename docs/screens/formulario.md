# Pantalla: Formulario

## Propósito
Usar una pantalla compartida para crear y editar productos.
## Campos
Nombre, precio, categoría y stock.
## Validación
Nombre obligatorio y máximo 60 caracteres; precio numérico mayor que cero; categoría permitida; stock entero mayor o igual a cero. Los mensajes del servidor se muestran si la API rechaza los datos.
## Navegación
Al guardar, abre el detalle del producto; Cancelar vuelve a la lista.
