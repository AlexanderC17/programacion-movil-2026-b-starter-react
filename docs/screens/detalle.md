# Pantalla: Detalle

## Propósito
Consultar todos los campos de un producto usando `GET /api/products/:id`.
## Elementos y acciones
Muestra id, nombre, precio, categoría y stock; incluye Editar, Eliminar y Volver.
## Errores
Presenta un mensaje si el producto no existe o falla la conexión. Eliminar requiere confirmación y, si tiene éxito, vuelve a la lista.
