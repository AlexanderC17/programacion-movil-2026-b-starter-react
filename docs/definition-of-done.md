# Definition of Done — Catálogo de productos

- [ ] Los siete documentos de `docs/` fueron revisados y adaptados por el estudiante.
- [ ] El commit de documentación precede al primer commit de código.
- [ ] Los cinco endpoints cumplen rutas, validaciones, filtros y códigos HTTP.
- [ ] La app implementa lista, detalle, formulario, edición y eliminación.
- [ ] La lista presenta carga, vacío, sin resultados y error con reintento.
- [ ] La app valida el formulario y muestra `details` de la API.
- [ ] Kotlin compila y ejecuta los tres productos.
- [ ] `npm test`, `npm run build` y, si está configurado, `npm run lint` fueron ejecutados.
- [ ] `.env` está ignorado y `.env.example` no contiene secretos.
- [ ] Se realizaron al menos seis commits Conventional Commits.
- [ ] El README explica ejecución y contiene las dos secciones en inglés.
- [ ] Se abrió un Pull Request hacia `main` del propio fork con descripción y checklist.
- [ ] Se copió el enlace del PR en Moodle antes del cierre.
